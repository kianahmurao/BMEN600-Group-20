## Biomedical Problem: Parkinson’s disease is a degenerative disorder that affects the central nervous system, resulting in motor and non-motor dysfunction such as slowness of movement, tremor, muscle stiffness, and cognitive and sleep problems. Real-time monitoring of movement features using a wearable device, by analysing distinct movement patterns, could determine a digital measure of the disease severity index; similarly, it can be used to detect changes early. 

## Research Question: Can wearable-derived movement features predict Parkinson’s disease severity when compared to healthy controls, using movement deviation over the disease duration as surrogate clinical severity labels?
